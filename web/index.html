Проверенные данные с собой

Соберите пакет JSON и передайте его на телефон. В него попадут только подтверждённые числа, реквизиты замеров, нормы и сведения об источниках.

Оригиналы фотографий остаются на ПК. Пакет содержит их имена и SHA-256.

Выгрузка всех данных для анализа

В файл попадут все замеры, включая поля на сверке и отклонённые варианты. У каждого значения будут ключ, название, тег, единица, статус и исходники — формат подходит для передачи нейросети или анализа.

Как открыть на телефоне

Мобильная часть находится в папке mobile. Для установки PWA нужен HTTPS. Локально на этом ПК её можно проверить по ссылке сверху.

В мобильном справочнике откройте «База» и импортируйте JSON. После установки интерфейс и база доступны без сети.

Пакет для телефона не заменяет резервную копию ПК. Для полного восстановления сохраните всю папку data при остановленном приложении.

Профиль и готовность данных

Каждый замер виден в диагностике. Незаданные признаки можно заполнить в журнале замеров. Статистика без пересчёта на нагрузку.

JSON после распознавания

Формат grades → measurements → values; дополнительные поля — extra. Все распознанные поля требуют сверки. Существующий замер дополняется без замены его реквизитов.

Фото для сверки

Исходный JSON сохраняется вместе с SHA-256. Подтверждение требует фото/PDF и причины решения.
