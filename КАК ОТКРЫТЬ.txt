РАБОЧЕЕ МЕСТО НА ПК

Дважды нажмите ярлык «Режимы марок УПЭ» на рабочем столе
или файл start.bat в папке C:\MARKI.
Главная страница откроется в браузере автоматически.
Оставьте окно «Rezhim UPE - Server» открытым: закрытие окна
останавливает сервер. Повторный запуск открывает браузер,
не создавая второй сервер.

МОБИЛЬНЫЙ СПРАВОЧНИК НА ПК — ДЛЯ ПРОВЕРКИ

Запустите рабочее место и нажмите «Открыть справочник» справа вверху.
В справочнике выберите «База» и импортируйте пакет JSON.
Готовый пакет после миграции: C:\MARKI\output\rezhim-15803-020.json.
После правок на ПК соберите свежий пакет через «Пакет для телефона».

ПРИЛОЖЕНИЕ ДЛЯ ANDROID (APK) — ОСНОВНОЙ СПОСОБ

Файл: C:\MARKI\output\Marki-UPE-3.0.apk (около 380 МБ, внутри вся база
и все фотографии). Скопируйте его на телефон, откройте и разрешите
установку из этого источника. Версия ставится поверх 1.3 и 2.0.
Сеть после установки не нужна, импортировать JSON не нужно.
Добавленные на телефоне фото, значения и решения хранятся отдельно
и сохраняются при установке новой версии APK. Удаление приложения их
стирает — перед удалением сохраните «База и JSON» → «ZIP: JSON +
добавленные фото».
Чтобы перенести на телефон изменения, сделанные на ПК, выполните
android_build.ps1 в папке C:\MARKI и установите новый APK.
Подробности — ANDROID_REPORT.md.

УСТАНОВКА ВЕБ-СПРАВОЧНИКА (PWA) НА ТЕЛЕФОН

Сначала мобильную часть нужно разместить по защищённому адресу HTTPS.
Сейчас такого адреса ещё нет. Адрес 127.0.0.1 работает только на ПК,
а пересылка одного HTML-файла не устанавливает офлайн-приложение.

После размещения откройте выданную ссылку на телефоне при наличии сети
и выберите «Установить приложение» или «На экран Домой» в браузере.
Передайте на телефон пакет JSON и импортируйте его на вкладке «База».
После установки и импорта справочник работает без интернета.

ПРИЁМ JSON И СВЕРКА НА ТЕЛЕФОНЕ

Откройте «Приём JSON», выберите файл распознавания и приложите фото.
Все поля сначала требуют сверки. Сравните число с фото и нажмите
«Подтвердить». Ошибочное число исправьте и укажите причину.
Дополнительный параметр можно связать со словарём или задать его
ключ, название и единицы. Признаки режима заполните в той же форме.
Подтверждения сохраняются на устройстве и используются в справочнике.
Если для профиля не хватает признаков, справочник показывает причины.

Для передачи на ПК сохраните «JSON для ПК» и фото отдельно.
На ПК такой JSON снова поступает на сверку, автоматической синхронизации нет.
Экспорт текущей базы сохраняет подтверждённые числа, но не фотографии
и не незавершённые решения: сохраняйте также исходный JSON, JSON для ПК
и фотографии. Не очищайте данные браузера до сохранения файлов.
